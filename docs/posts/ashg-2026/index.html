Some new works on molecular QTL methods

  • Using multiple PC across ancestry
    • Linear mixed effect model...
    • Isn't PC correlated with cell types?
    • Are we imply recapitulating cell type QTL?
    • Expression PCs are computed from expression and also track cell type, so they sit downstream of both genotype and expression: a collider.
    • Adjusting for a collider opens the path G → C ← E, so PC correction can create or distort the genotype–expression association rather than only remove confounding.
